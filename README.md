# zona3d
Proyecto enfocado en el diseño y desarrollo de una experiencia web para una marca de impresión 3D personalizada.

Exploré decisiones visuales, jerarquías de contenido, tipografía, micro-interacciones y composición responsive, buscando construir una interfaz moderna y alineada con la identidad tecnológica de la marca.

También se trabajó sobre la comunicación visual de materiales, productos y procesos, priorizando claridad y experiencia de usuario.

Deo del proyecto: https://lihuelm.github.io/zona3d/
